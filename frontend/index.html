Cara Kerja

Mulai dalam Hitungan Menit

  1. 1

    Register

    Daftarkan barbershop Anda lewat form singkat.

  2. 2

    Choose Package

    Pilih paket sesuai kebutuhan toko Anda.

  3. 3

    Payment

    Bayar aman lewat QRIS, Virtual Account, atau kartu (Midtrans).

  4. 4

    Tenant Activated

    Toko Anda otomatis aktif begitu pembayaran berhasil.

  5. 5

    Login

    Masuk ke dashboard toko Anda sendiri.

  6. 6

    Start Using System

    Kelola booking, barber, dan laporan sehari-hari.
